# Illymolly 단축키 (Adobe Illustrator 호환)

> macOS 에서는 `Ctrl` 을 `⌘(Command)` 로 읽으세요. 코드에서 `metaKey` 로 자동 매핑됩니다.
> 단축키는 물리적 키 위치(`event.code`) 기준으로 인식하므로 한/영 입력 상태와 무관하게 동작합니다.

## 브라우저와 겹치는 단축키

브라우저 탭 안에서는 아래 11개를 브라우저가 먼저 가져가 앱에 도달하지 않습니다.
**대체 키는 언제나 함께 동작하므로** 그대로 쓰시면 됩니다.

| 앱 단축키 | 명령 | 브라우저가 하는 일 | 대체 키 |
|---|---|---|---|
| `Ctrl+1` | 실제 크기 | 탭 1 로 이동 | `Alt+1` |
| `Ctrl+2` | 잠금 | 탭 2 로 이동 | `Alt+2` |
| `Ctrl+3` | 숨기기 | 탭 3 으로 이동 | `Alt+3` |
| `Ctrl+5` | 안내선 만들기 | 탭 5 로 이동 | `Alt+5` |
| `Ctrl+6` | 재선택 | 탭 6 으로 이동 | `Alt+6` |
| `Ctrl+7` | 클리핑 마스크 만들기 | 탭 7 로 이동 | `Alt+7` |
| `Ctrl+8` | 컴파운드 패스 만들기 | 탭 8 로 이동 | `Alt+8` |
| `Ctrl+N` | 새로 만들기 | 새 창 | `Alt+N` |
| `Ctrl+W` | 닫기 | 탭 닫기 | `Alt+W` |
| `Ctrl+Tab` | 다음 문서 | 다음 탭 | `Ctrl+Alt+→` |
| `Ctrl+Shift+Tab` | 이전 문서 | 이전 탭 | `Ctrl+Alt+←` |

원래 키를 그대로 쓰려면 둘 중 하나를 켜세요.

- **파일 > 앱으로 설치** — 탭 없는 창으로 띄우면 `Ctrl+1~9` · `Ctrl+Tab` 이 풀립니다. 오프라인에서도 열립니다.
- **보기 > 단축키 완전 사용** — 전체 화면 + 키보드 잠금으로 `Ctrl+W` 까지 전부 앱이 받습니다 (크롬 · 엣지).
  나가려면 `Esc` 를 길게 누릅니다.

**보기 > 단축키...** 에서 지금 환경 기준의 전체 목록을 확인할 수 있습니다.

`Space`(임시 손 도구) · `Ctrl+R`(눈금자) · `Ctrl+S`(저장) · `Ctrl+P`(윤곽선 붙여넣기) 등
나머지는 캡처 단계에서 브라우저 기본 동작을 막으므로 그대로 동작합니다.

`Ctrl+V` · `Ctrl+Shift+V` 는 **일부러 막지 않습니다.** 브라우저가 내주는 `paste` 이벤트를
통해야만 시스템 클립보드에 닿을 수 있어서입니다. 덕분에 다른 프로그램에서 복사한
이미지 · SVG · 글자를 `Ctrl+V` 로 그대로 가져옵니다.

`Ctrl+C` · `Ctrl+X` 는 반대로 앱이 직접 처리합니다 — `copy` 이벤트는 오지 않을 수도 있는데,
복사만큼은 확실해야 하기 때문입니다.

도구 아이콘을 **더블클릭**하면 해당 도구의 옵션 대화상자가 열립니다
(사각형·원·다각형·별·선분 크기, 회전/크기 조절/반사/기울이기, 브러시·지우개 폭 등).
도형 도구로 캔버스를 **클릭**(드래그 없이)해도 크기 입력 대화상자가 열립니다.
회전·크기 조절·반사 도구로 캔버스를 `Alt+클릭` 하면 기준점 지정과 동시에 대화상자가 열립니다.

도구 아이콘을 **길게 누르거나 우클릭**하면 숨은 도구(둥근 사각형, 다각형, 별, 그룹 선택, 기울이기, 매끄럽게 …) 플라이아웃이 열립니다.

## 대지

| 키 | 명령 |
|---|---|
| `Alt+PageDown` | 다음 대지 |
| `Alt+PageUp` | 이전 대지 |
| `Ctrl+Alt+C` | 대지를 선택 항목에 맞추기 |

`대지` 패널에서 대지 목록을 보고 추가 · 복제 · 삭제 · 옵션 편집 · 모두 재정렬을 할 수 있습니다.
목록 항목을 클릭하면 그 대지로 이동하고, 더블클릭하면 대지 옵션이 열립니다.

상태 표시줄의 `⏮ ◀ 대지 n (i/N) ▶ ⏭` 로도 이동할 수 있습니다.
