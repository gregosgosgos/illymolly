# Illymolly 단축키 (Adobe Illustrator 호환)

> macOS 에서는 `Ctrl` 을 `⌘(Command)` 로 읽으세요. 코드에서 `metaKey` 로 자동 매핑됩니다.
> 단축키는 물리적 키 위치(`event.code`) 기준으로 인식하므로 한/영 입력 상태와 무관하게 동작합니다.

## 도구 (Tools)

| 키 | 도구 |
|---|---|
| `V` | 선택 도구 |
| `A` | 직접 선택 도구 |
| `Y` | 자동 선택 도구 |
| `P` | 펜 도구 |
| `+` (`=`) | 고정점 추가 도구 |
| `-` | 고정점 삭제 도구 |
| `Shift+C` | 고정점(기준점 변환) 도구 |
| `T` | 문자 도구 |
| `\` | 선분 도구 |
| `M` | 사각형 도구 |
| `L` | 원형 도구 |
| `B` | 페인트브러시 도구 |
| `Shift+B` | 물방울 브러시 도구 |
| `N` | 연필 도구 |
| `Shift+E` | 지우개 도구 |
| `C` | 가위 도구 |
| `R` | 회전 도구 |
| `O` | 반사 도구 |
| `S` | 크기 조절 도구 |
| `E` | 자유 변형 도구 |
| `G` | 그레이디언트 도구 |
| `I` | 스포이드 도구 |
| `Shift+O` | 대지 도구 |
| `Z` | 확대 도구 |
| `H` | 손 도구 |
| `Space` (누르고 있는 동안) | 임시 손 도구 |

도구 아이콘을 **길게 누르거나 우클릭**하면 숨은 도구(둥근 사각형, 다각형, 별, 그룹 선택, 기울이기, 매끄럽게 …) 플라이아웃이 열립니다.

## 칠 / 획

| 키 | 동작 |
|---|---|
| `X` | 칠 ↔ 획 초점 전환 |
| `Shift+X` | 칠과 획 교체 |
| `D` | 기본 칠(흰색)/획(검정) |
| `/` | 없음(None) |
| `,` | 단색 |
| `.` | 그레이디언트 |

## 파일

| 키 | 명령 |
|---|---|
| `Ctrl+N` | 새로 만들기 |
| `Ctrl+O` | 열기 (`.illy.json`, `.svg`) |
| `Ctrl+S` | 저장 |
| `Ctrl+Shift+S` | 다른 이름으로 저장 |
| `Ctrl+Shift+P` | 가져오기(이미지 배치) |
| `Ctrl+Shift+E` | SVG로 내보내기 |
| `Ctrl+Alt+E` | PNG로 내보내기 |
| `Ctrl+Alt+P` | 문서(대지) 설정 |

## 편집

| 키 | 명령 |
|---|---|
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+Shift+Z` | 다시 실행 |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 오려두기 / 복사 / 붙이기 |
| `Ctrl+F` | 앞에 붙이기 |
| `Ctrl+B` | 뒤에 붙이기 |
| `Ctrl+Shift+V` | 제자리에 붙이기 |
| `Delete` / `Backspace` | 지우기 (직접 선택 상태에서는 선택 앵커 삭제) |
| `Ctrl+Alt+D` | 복제 *(Illymolly 추가 기능)* |

## 마우스 / 드래그 보조키

| 조작 | 동작 |
|---|---|
| `Shift` + 드래그 | 이동 축 고정 / 정사각·정원 / 45° 단위 |
| `Alt` + 드래그(선택 도구) | 복제하며 이동 |
| `Alt` + 드래그(도형 도구) | 중심에서부터 그리기 |
| `Alt` + 바운딩 박스 핸들 | 중심 기준 크기 조절 |
| `Shift` + 바운딩 박스 핸들 | 비율 유지 |
| 코너 핸들 **바깥쪽** 드래그 | 회전 |
| 더블 클릭(그룹) | 격리 모드 진입 |
| 더블 클릭(텍스트) | 텍스트 편집 |
| 휠 | 상하 스크롤 |
| `Shift` + 휠 | 좌우 스크롤 |
| `Alt`(또는 `Ctrl`) + 휠 | 확대/축소 |
| 눈금자에서 캔버스로 드래그 | 안내선 생성 |
| 다각형·별 도구 드래그 중 `↑` `↓` | 변(꼭짓점) 개수 증감 |
| 그레이디언트 패널 막대 클릭 | 정지점 추가 |
| 그레이디언트 정지점 드래그 | 정지점 이동 |
| `↑` `↓` `←` `→` | 1pt 이동 (`Shift` = 10pt, `Alt` = 복제 후 이동) |
